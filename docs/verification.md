# Проверка восстановления — 2 октября 2026

Проверена окончательная реализация с защитой от неразличимых кратных корней
и исправлениями по результатам отдельного ревью.

| Среда | Результат |
| --- | --- |
| macOS arm64, Apple Clang 21, Release | CMake/CTest: оба набора прошли |
| macOS, Python 3.10 | 24 теста, включая сравнение с C++, прошли |
| macOS, Python 3.13 через CTest | Python и сравнение с C++ прошли |
| Linux-контейнер, GCC 14.2, Python 3.12.14 | Численный C++-набор и Python/межъязыковые проверки прошли |
| macOS, AddressSanitizer + UndefinedBehaviorSanitizer | Оба CTest-набора прошли без диагностик |
| Ruff | Форматирование и проверки `F,E9` прошли |
| Python-пакет | Wheel/sdist собраны, wheel установлен и CLI запущен вне исходного дерева |
| Архив | Преобразование UTF-8/LF → Windows-1251/CRLF побайтно совпадает с оригиналом |

Проверки включают аналитический случай `alpha=0`, движение с постоянным
ускорением, три переключения, независимую квадратуру стоимости, отклонение
шага, лимит вычислений, некорректные параметры, ошибки CSV/stdout, почти кратные
корни и масштабирование стрельбы. Случаи, найденные ревью, закреплены тестами.

Контрольный запуск с параметрами по умолчанию:

```text
p             = 0.9067263583342234
switches      = 0.7129680343219460, 0.7982063366339809
x(1)          = -0.4583333332536704
I(1)          = -0.5433316502178236
x(1) - target = 7.97e-11
```

Последние разряды зависят от платформы. GitHub Actions подготовлен, но удалённо
не запускался: пользователь выбрал только локальную подготовку проекта.

Повторить проверки можно командами из [README](../README.md).
