# Журнал восстановления

## Что сохранено

- Исходные байты `текст программы.txt` остались нетронутыми локально.
- Локальный `archive/original.cpp` содержит тот же код в UTF-8/LF.
  Каталог `archive/` исключён из Git и отсутствует в чистом клоне репозитория.
- Сохранены система ОДУ, функционал стоимости, исходные параметры задачи,
  таблица Дормана—Принса и идея стрельбы с релейным управлением.
- Сопряжённый параметр `p` не смешивается с весом `alpha`: в старом коде для них
  использовались похожие имена `alpf` и `alph1`.

решение. Корректность проверяется по аналитическим формулам и независимой квадратуре.

## Границы проекта

Поддерживается восстановленная задача на `[0,1]` с нулевыми начальными положением
и скоростью, `alpha≥0` и конечной координатой строго внутри `(-0.5,0.5)`.
Это небольшой учебный проект, а не универсальная библиотека оптимального управления.
Дублирующие и закомментированные эксперименты старого исходника, в том числе
обратное интегрирование, сохранены только в архиве.

Все расчёты идут в двойной точности. Почти кратные корни, экстремальные параметры
и допуски ниже машинной точности могут приводить к отказу с сообщением об ошибке.
Около неразличимых касаний и слияния корней решатель явно возвращает
`ill-conditioned switching roots`, вместо выдачи ненадёжных времён переключения.
Совпадение Python и C++ дополняет аналитические проверки, но само по себе не
доказывает математическую корректность.

## Подготовка к GitHub

Пользователь выбрал только локальную подготовку. Репозиторий на GitHub не создаётся,
remote не добавляется, push не выполняется. Локальные `.env`, настройки редактора,
сборки и результаты исключены из Git. Лицензия не выбрана: её следует определить
владельцу перед публикацией с разрешением на повторное использование.
